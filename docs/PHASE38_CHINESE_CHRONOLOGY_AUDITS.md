## Original Phase 05 player: safe second unsent draft

Phase 37 protects a single independently written but unsent working draft when restoring submitted versions. Phase 38 adds an **explicit second protected unsent draft**, which fixes a real writing workflow limitation: a learner can now protect *two different unsent edits independently*, voluntarily switch to previously submitted revision history, then restore either saved unsent version without silently overwriting the other. The UI's **Protect this second unsent draft** action becomes available only after the first protected copy exists and the learner independently writes a different unsent response. **Second protected unsent draft** displays this copy and offers **Restore second unsent draft**; the original first-copy restore and three-entry submitted-revision history continue to work. Only a real user action can capture the second copy, and a third distinct unsent copy cannot silently overwrite either protected one. Previous ungraded feedback is cleared after restore, so Continue still requires explicit re-review. Original reducer remains sole source of truth for these actions; no duplicate player, automatic grading, native scheduler or persistence is introduced. Both protected copies disappear on reset, load and page refresh.
