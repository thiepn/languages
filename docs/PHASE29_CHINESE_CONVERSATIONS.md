## Four concrete learner-owned dialogue scenarios

1. **Two visiting groups change the speaker:** a visitor rather than a host leads a group orientation, changing the perspective of 我, 我们 and 你们.
2. **A returning buyer and a new tea guest:** a returning customer asks about an apple *before* a new visitor arrives, so 这个苹果很好吃。 precedes the later 你好 and 你喜欢喝茶吗？.
3. **A visitor corrects a mistaken school role:** another person is identified as teacher, then a false role is negated, then the current student self-identifies with 我是学生。.
4. **A colleague's shared role before a badge check:** 也是 introduces additional role identity, then the speaker clarifies possession with 我的, and later rejects an incorrect identity using 不是.

These tasks deliberately **invert** an earlier learner source-evidence order when a speaker or event changes. The same words remain original attested citations, and the pedagogical order is independently authored situational practice. The phrases are not represented as an originally recorded multi-line conversation.
