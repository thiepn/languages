## Four substantial three-person skill scenarios

1. **Three speakers repair a team meeting.** One moderator discusses their own team using 我们, another speaker changes the purpose to addressing plural visitors through 你们, and a third individual interpreter clarifies an individual report through 我. The fifth new evidence sequence is 我们 → 你们 → 我, with separate explanations rejecting four previously valid but contextually wrong sequences.
2. **Three customers change a market conversation.** The first returning customer needs an apple-quality statement 这个苹果很好吃。, a second needs the drink-preference question 你喜欢喝茶吗？, and a third new arrival needs 你好. The actual timing makes the fifth source sequence apple → tea → greeting, rather than the four prior arrival sequences.
3. **Student, clerk and teacher resolve an identity mistake.** A student identifies themself positively with 我是学生。, later denies the incorrectly printed teacher role with 不是 and finally points to the actual teacher using 他是老师。. This fifth order is student → denial → teacher rather than prior introductions.
4. **A badge, a colleague and a false job title.** The receptionist first affirms a colleague's additional role using 也是, then another worker denies a false professional label with 不是, and an unrelated guest finally claims a badge with 我的. The fifth order is additional role → denial → ownership.
