# Phase 32 supplementary writing restoration

The original Phase 32 branch head `52aac2febc484008837140d3211a30c206b3b1e4` already implemented four new source-pinned three-speaker Chinese scenarios (49 unpublished editorial candidates total; the original 12 canonical lessons and 126 exercise IDs remain unchanged), five independent comprehension/sequence tasks and a ninth ungraded dialogue on the Phase 05 player. This supplementary implementation preserves those new lessons and all prior 45 candidates as compiled; it adds a genuine player workflow that had previously been missing from first-draft comparison.

After an author submits a second ungraded written response and opens the already existing **Compare first draft** section, **Restore first draft** explicitly places their original writing back into the *editable* textarea. It clears the previous ungraded outcome (so Continue remains disabled until the learner reviews the restored/newly revised text), keeps its original source rubric, first submitted draft and submission count, and never invents a grade or silently persists a draft. The control is not available for first submissions, unchanged initial drafts, recognition questions, or lessons without an original submitted draft. Reset, reload and lesson switching discard all attempts and first-draft comparison, exactly as before.

Implementation uses a new `restore-first-draft` action on the original Phase 05 reducer and a button in the already existing writing comparison panel. It does not introduce a new component library, revision database, evaluator, checker, scheduler or data API. React continues to render the existing original player's `FrameAttempt` and the native Chinese app remains the sole owner of local-first history, progress and FSRS/scheduling.

New Node tests exercise all nine Phase 32 independent writing tasks, restore before submit/revise (no effect), initial and subsequent draft submission, restored editing, inability to continue before resubmitting, third submission, preservation of first draft, reset/load loss and no impact to recognition tasks or canonical checkpoint-only storage. The existing real Playwright Phase 32 journeys are extended in desktop/mobile Chromium, Firefox and WebKit to compare, restore, edit and resubmit the ninth independent Chinese writing response, including the 320px full journey. Exact source Hanzi, original tone-marked Pinyin, DEMO_ONLY rights (review-required, pending, redistribution unverified), Phase 16 quotation evidence, Phase 25 Pinyin manifest, Phase 21 corrections and Account/Core/Hub boundaries remain untouched.
